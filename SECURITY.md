# Security policy

Please report security issues privately by email to **contact@guardx.to**. Do not open a public issue or discussion for them.

This applies to the code in GuardX's public repositories and to the guardx.to website. Our machine-readable contact is at [guardx.to/.well-known/security.txt](https://guardx.to/.well-known/security.txt).

A useful report says what you found, where, and how to reproduce it. We read reports in English and German.

Please do not run load tests, floods or automated scans against guardx.to or against websites that use GuardX.
